This folder contains my final project for my ISAT B321 Database Driven App Development class. For this final project we were tasked with creating a frontend application using C# to create an app that would allow instructors to create and schedule meetings with their student. I created the frontend application including it's UI, Methods, and overall design. I also cleaned and organized the data used for this project and created stored procedures that are linked to the methods used in the application. 

This application contains full CRUD functionality and meetings between students and instructors are able to be scheduled. This application fulfils its desired purpose.
