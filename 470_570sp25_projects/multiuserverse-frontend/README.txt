Title: Multiuserverse
Author: James Plant with assistance from Dr. Canada

Purpose: this project was created as an introduction to full stack web development through my Software System Process ISAT B470 class.

This project was created through multiple assignments during my Software System Process course. The class was instructed to create the same project while following instructions given by our instructor. I was able to create this project using Spring boot on the java back end and react on the frontend. Multiuserverse displays basic CRUD functionality and authentication and runs in browser locally and through online hosting services like Netlify.
